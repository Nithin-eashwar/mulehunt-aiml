# Scam-message dataset

`messages.csv` (5,725 messages) is built by `python -m text.build_corpus` from three sources.
Each source is labelled in the `source` column. **No message was collected from a person.**

| `source` | File | What it is | Real? | Messages |
|---|---|---|---|---|
| `public` | `public/uci_sms_spam_collection.tsv` | UCI SMS Spam Collection: real English SMS (UK/Singapore, ~2011); ham → genuine, spam → scam / `other_scam` | real, not Indian | 5,109 |
| `reported` | `public/reported_patterns.csv` | written by us from scam messages described in cited Indian news, bank, police and government advisories; **each row has its source URL** | real patterns, our wording | 56 |
| `synthetic` | `public/synthetic_messages.csv` | generated by `python -m text.synthetic` (seed 0) from templates: Indian scams of the five types plus `other_scam`, and ordinary Indian genuine messages (bank alerts, OTPs, family chat), in English, Hinglish and Hindi | synthetic | 560 |

`sample_messages.csv` (36 messages, `source = self`) holds the test fixtures and dashboard examples. It is synthetic and is not part of `messages.csv`.

Schema: `msg_id, text, label, scam_type, language, channel, source`
- `label` in {scam, genuine}; `scam_type` in {fake_kyc, digital_arrest, job_task, loan_app, fake_investment, other_scam, genuine}
- `language` in {english, hindi, hinglish, other}; `channel` in {sms, whatsapp, other}; `source` in {form, self, public, reported, synthetic}

All texts go through `text/anonymise.py`, so phone numbers, links, UPI IDs, OTPs and account numbers become `<PHONE>`, `<URL>`, `<UPI>`, `<OTP>`, `<ACCOUNT>` in every source.
