# Data validation report

Real transaction data is legally unavailable; we built a simulator calibrated to NPCI/RBI statistics and validated against the IBM AML benchmark.

Generated by `python -m simulator.validate`. Targets and sources come from `simulator/config.yaml` and `data/raw/calibration_sources.md`.

## Dataset

```
50,445 accounts (1.13% fraud labels), 1,800,306 transactions (0.519% fraud)
```
